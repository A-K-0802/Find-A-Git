# GitHub Repository Finder using LangChain & Google Gemini

## Features:

-  **Natural Language Interface**: Ask in plain English (e.g., _"pathfinding in Java"_).
-  **LLM + Tool Agent**: Google Gemini is used as an LLM agent with a tool that fetches GitHub data.
-  **GitHub API Integration**: Fetches real-time data using GitHub's REST API.
-  **Streamlit UI**: Easy-to-use frontend for interaction.

## Tech Stack

- [LangChain](https://www.langchain.com/) (GoogleGenerativeAI integration)
- [Google Gemini (1.5 Flash)](https://ai.google.dev/)
- [Streamlit](https://streamlit.io/)
- [GitHub REST API](https://docs.github.com/en/rest)
